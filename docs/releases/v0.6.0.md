## Upgrading from 0.5.4

No configuration change is needed. With no `decision` setting, routr keeps asking TypeSafe's Jev, as before, with your
saved TypeSafe key and the same `sure_at` (0.8). Your subscriptions, models, effort, reserves and update channel are
preserved.

To try another decision model, run `routr setup` and choose "Decision model" from its menu, or let an agent run
`routr setup --yes --decision <typesafe|cloudflare|ollama>[:<model>]`. A `sure_at` you set yourself is kept and applies
to every decision model. If an older setup wrote `"sure_at": 0.8` into your config, changing the decision model (or
`routr setup --force`) drops that line, and setup says so, so the model's own measured bar applies instead. If you
chose 0.8 yourself, put it back.

The update reinstalls routr's skills. Ask an agent that already loaded routr to reread the skill, or start a new
session.

## Highlights

- **Choose your decision model.** routr can now read briefs with Cloudflare's open Clef models as well as TypeSafe's
  Jev:
  - **Jev** stays the default, and reads the level of work most accurately on routr's tests (82 to 83 of 104 labelled
    briefs).
  - **Clef on Workers AI** (`cloudflare`, or `cloudflare:clef-flash` for the smaller model) runs on your Cloudflare
    account. It needs an API token with Workers AI Read, and Workers AI's free daily allowance covers about 200 briefs a
    day. Clef got 72 of 104 levels right and reads levels too high more often; Clef Flash got 74 and reads them too low.
  - **Clef Flash through Ollama** (`ollama`) is free and runs on your machine; nothing leaves it. It needs Ollama 0.40.1
    or later and a GPU or Apple Silicon. Run `ollama pull clef-flash:9b-mxfp8` on Apple Silicon (12 GB) or
    `ollama pull clef-flash:9b-q8_0` elsewhere (11 GB). It got 70 to 72 of 104 levels right, reading them too low more
    often.
  - Each model is read with its own measured profile, and the advice says which model answered (`decision_model`). All
    the numbers, with dates, are in [docs/evidence.md](https://github.com/sirkirby/routr/blob/main/docs/evidence.md#decision-models).
- **`routr key set cloudflare`** saves a Cloudflare token and account ID beside your TypeSafe key, owner-only, and
  tests them. Ollama needs no key. `routr doctor` shows which decision model answers and the fix its provider needs,
  including an Ollama that is not running, a model that is not pulled, or an Ollama older than 0.40.1.
- **Workers that ask a question are noticed.** The worker guide now forbids a harness's own ask-the-user tool
  (Codex's question box, Claude's AskUserQuestion): a blocked worker ends with `VERDICT: blocked` and says what it
  needs. The orchestrator guide says to wait with a timeout and to read the last lines of a worker that has been
  working a long time. A Codex question box under running background terminals reads as `working` in herdr (measured
  2026-10-11).
- **`routr launch` delivers tasks more reliably.** It sends a task only after two ready readings 1.5 s apart: under
  load, a Claude worker had once read ready and never received its task. It waits up to 5 s through a moment in which
  herdr sees no agent while Cursor starts. When a task still never arrives, `needs_input.then` names the exact
  `routr launch … --pane` rerun, which keeps launch's wrapping around the task.
- **Antigravity's consent screen.** agy 1.3.3 opens a "Terms of Service & Data Use" screen that herdr reads as idle.
  launch reports `needs_input` there and does not resend. Answer it once yourself by running `agy` in your terminal.

## Verification

Measured on 2026-10-11:
- **Decision models:** each model was run by the maintainers' gate beside Jev on the same 104 labelled briefs and 36
  real tasks.
- **Ollama on Windows:** Clef Flash on an RTX 5090 laptop took about 0.8 s per call, and its answers matched the Mac's
  within 0.018 on every probability of 5 briefs. Ollama 0.40.0 could not run Clef there at all, which is why routr asks
  for 0.40.1. On that laptop's CPU alone a brief took 36 to 41 s, longer than routr waits (30 s).
- **Cloudflare:** a token with only Workers AI Read worked for `key set`, setup, doctor and both models.
- **Launches:** Claude 5 of 5, Codex 4 of 4 and Cursor 4 of 4 received their task and answered, launched one at a time
  and three at once. Kiro was not tested.

Not measured:
- Clef Flash on Linux: it is the same build and code path that was measured on Windows.
- LM Studio's new System One endpoint, which routr does not offer yet.

## CLI and JSON compatibility

**Advice JSON and ledger rows:**
- `provider` and `decision_model` replace `jev_model`.
- Ledger rows written before this release are read as TypeSafe's.

**Telemetry:**
- Sent rows move to `v: 3` with the same two fields, and share rows to `v: 2`. See
  [docs/telemetry.md](https://github.com/sirkirby/routr/blob/main/docs/telemetry.md).
- Telemetry stays off unless you turned it on.

**Config:**
- New `decision: { "provider", "model" }` setting.
- `sure_at` is now unset by default, which means the answering model's own measured bar (Jev's is 0.8).

**Commands:**
- `routr key set` takes an optional provider (`typesafe` or `cloudflare`). With none, it uses the one your settings use.
- `routr setup` takes `--decision`.
