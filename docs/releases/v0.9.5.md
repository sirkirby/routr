## Upgrading from 0.9.4

No configuration change is needed. The update reinstalls routr's skills, and the worker guide changed. An agent that
already loaded routr reads the older guide until it rereads the skill or starts a new session.

## Changed

- **Workers are told how to set a subagent's model and effort on their harness.** The worker guide already asked them
  to choose both, but not how. In 60 days of the maintainer's Claude Code worker transcripts, 33 spawns set a model 31
  times and effort 10 times. The guide now lists what each harness takes:
  - Claude Code and Codex take a model and an effort on the spawn.
  - Cursor takes a model from a short list, and the id carries the effort.
  - Antigravity takes a model tier, but a `model` line in the agent's own file wins, even `inherit`. No effort setting
    was found.
  - Kiro accepts a model on a `subagent` stage, but which model ran could not be confirmed. No effort setting was found.
- **A skill's subagents.** The guide also says that a skill which starts its own subagents, such as Claude Code's
  `/code-review`, names no model, so they get your harness's subagent default or your own model.
- **`routr subagent`'s next step** says to set both on the spawn, and points to the guide.
- **`routr record --subagent` and the report's `SUBAGENTS:` line** take an optional effort as a fourth part:
  `<subtask> → <level> → <model> → <effort>`. Three-part lines still work. `routr assess` shows the effort beside the
  model.

## Compatibility

A ledger row's `subagents` entries may now carry `effort`; it is absent when none was given. The effort stays in your
local ledger: telemetry, `routr share` and OpenTelemetry do not send it, and their documented fields are unchanged.

One limit: only a known effort level after the last arrow counts as the effort, so a model name that holds an arrow and
ends in such a word (`local->auto`) reads as model plus effort.

## Verification

- `bun test`: 773 pass, 7 skip, 0 fail; all three platform jobs green.
- The harness settings were measured on 2026-11-02 with one short run per setting, read from each subagent's own
  record: Claude Code 2.1.316, Codex 0.166.0, Cursor 2026.10.22, Antigravity 1.4.12, Kiro 2.36.0.
- These runs show that the settings apply. They do not show that a smaller subagent keeps quality or saves usage, and
  routr's advice on when to spawn is unchanged.
- An independent review found two P2 issues and one P3, which were fixed and verified.
