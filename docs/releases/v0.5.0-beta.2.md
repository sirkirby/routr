This is a pre-release for the beta update channel (`routr setup --channel beta`). Stable users are not offered it.

## Upgrading from 0.5.0-beta.1

No configuration migration is required and setup has no new choices. The update reinstalls routr's skills, which
now include `routr-orchestrate`, and links them into Antigravity's skills folder as well. Ask an agent that already
loaded routr to reread the skill, or start a new session.

## Highlights

- **Start an orchestration with `/routr-orchestrate <your plan>`** (Codex: `$routr-orchestrate`). The session becomes
  the routr orchestrator: it loads routr, checks `routr doctor` and herdr, and sends every handoff through
  `routr dispatch` or `routr subagent`. It is meant to be typed by you, not chosen by the model. Measured 2026-10-05 by
  asking each harness to list the skills its model can see: hidden in Claude Code, Codex, Cursor (CLI) and
  Antigravity; listed in Kiro, where its description is the only guard. Where the command is not available, the same
  works as a prompt: "You're an orchestrator; use routr to manage the following work: ...".
- **Antigravity gets routr's skills.** Measured: Antigravity reads `~/.gemini/config/skills`, not `~/.agents/skills`.
  routr links both skills there.
- **npm-installed harnesses work on Windows.** routr could not start a harness CLI installed through npm (a `.cmd`
  shim such as `codex.cmd`), so such a harness never counted as signed in. routr now resolves commands the way a shell
  does and starts an npm shim's script directly. Checked on Windows CI with tricky arguments; not yet on a Windows
  desktop with real harness installs.
- **Skill installs touch only routr's own files.** Each skill folder routr writes carries a manifest of its files.
  A same-named skill of yours, a link to a checkout, a folder with files routr didn't write, or a folder it cannot
  read is left as it is and reported. Uninstall removes only routr's files. `routr doctor` checks every shipped file.

## Not yet verified

Windows desktop installs (npm and native) of each harness, and Linux. Reports from beta users are welcome
(`routr feedback "<text>"`).

## CLI and JSON compatibility

`routr skill install` and `routr uninstall` report folders they left alone in `kept`, exit 1 when a step fails, and
`routr doctor` lists each skill with where it is installed and any missing or extra files. Telemetry payloads are
unchanged.
