This is a pre-release for the beta update channel (`routr setup --channel beta`). Stable users are not offered it.
It carries the fixes from a final review of every change since 0.4.1, ahead of a stable 0.5.0.

## Upgrading from 0.5.0-beta.2

No configuration migration is required and setup has no new choices.

## Highlights

- **`routr doctor` no longer contacts GitHub.** The daily automatic update check records what it saw, and doctor
  shows it ("0.6.0 is available, seen 3 h ago"). With automatic updates off, it says `routr update --check` looks by
  hand. `routr setup` runs the same inspection, so it makes no update request either.
- **Updates cannot step backwards.** Manual and automatic updates share one lock, and routr checks the version of the
  binary actually installed before replacing it, so a slower, older download never overwrites a newer one. The update
  result and `update.log` say what happened to the skills (installed, kept and why, or failed).
- **Timed-out reads always end.** On macOS and Linux a read that times out is stopped with SIGTERM, then SIGKILL; on
  Windows a failed `taskkill` falls back to a direct kill and never keeps routr running. A herdr call returns on time.
- **Safer skill installs.** A manifest-less `routr` skill reached through a linked folder is never adopted or
  overwritten; a linked `~/.claude` or `~/.kiro` still gets routr's skills. Uninstall re-checks each folder right
  before removing it. Doctor requires the shared skill copy that Codex and Cursor read.
- **Claude usage:** a fresh `/usage` answer that shows no usage windows now wins over an old statusline snapshot, and a
  reset shown to the minute counts from the end of that minute.
- **launch:** a worker that disappears after its startup question is reported as failed; a pane whose agent could not
  be confirmed is not renamed.
- On Windows, doctor detects harnesses with the same lookup routr uses to start them, and a command that cannot be
  found fails clearly.

## Not yet verified

Windows desktop installs of each harness, and Linux. Reports from beta users are welcome (`routr feedback "<text>"`).

## CLI and JSON compatibility

`routr doctor --json` adds `update_seen_hours_ago` beside `update_available`. `routr update --json` reports the skill
outcome (installed, kept, failed) and `skill_reinstalled` is true only when nothing was kept or failed. Telemetry
payloads are unchanged.
